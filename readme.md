# Spotify Ambient

Synchronize your Philips Hue Entertainment Area with Spotify album artwork.

## Features

- 🎵 Spotify OAuth
- 🎨 Album artwork color extraction
- 💡 Hue Play Bars
- 🌈 Hue Gradient Strips
- ⚡ Adaptive polling
- 💾 Artwork cache

## Installation

### HACS

(Add repository)

### Manual

Copy

/custom_components/spotify_ambient

into

/config/custom_components/

Restart Home Assistant.
